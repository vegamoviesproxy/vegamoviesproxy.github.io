1.1 重新定义本地网络管理

传统代理工具往往局限于单设备使用，而Quantumult的局域网代理功能允许将一台设备（如iPhone或iPad）配置为局域网内的代理服务器，其他设备（如电脑、智能电视）通过连接该代理实现统一管理。这种架构特别适合：

二、实战配置：一步步搭建代理环境

2.1 前期准备工作

  1. 设备选择：建议使用常开机的iOS设备作为代理服务器
  2. 网络环境：确保主设备与客户端处于同一局域网段（如192.168.1.x）

2.2 详细配置流程（图文进阶版）

步骤1：创建代理服务器

步骤2：启用局域网共享

  • 进入「更多」→「局域网代理」

3. 如需认证，在浏览器弹出窗口输入Quantumult设置的用户名密码

FAQ

V2Ray 的 QUIC 传输模式有哪些优势？
QUIC 传输减少握手次数，支持多路复用和 UDP 基础，降低延迟并提高吞吐量。在不稳定或高丢包环境下，QUIC 可保证视频、游戏或即时通讯的稳定性和流畅体验。
Nekobox 如何在 Android 上导入配置？
打开 Nekobox，点击“导入配置”按钮，选择订阅链接或本地 JSON 文件。程序会解析后自动生成节点列表，用户可一键连接或测速筛选最优节点。
Nekoray 支持 Trojan 吗？
支持。Nekoray 基于 sing-box 核心，能兼容 Trojan、Vmess、Vless、Hysteria2 等多种协议。用户可在同一界面中管理和切换不同类型节点，非常方便。
如何为 Vmess 节点生成安全的 UUID？
UUID 应使用标准的 128 位格式，可使用系统命令如 `uuidgen` 或在线 UUID 生成器生成随机、唯一的 ID；不要使用默认或弱随机值，定期更换以降低被滥用或泄露的风险。
如何防止租用服务器被用作滥发或代理滥用？
限制对外端口与协议，使用防火墙与入侵检测（如 fail2ban），监控流量异常并设置告警，定期审计登录行为，及时阻断滥用源并与服务商沟通封禁滥用账户以防引起供应商封禁整台机。
VMess AEAD 加密在高封锁网络的作用？
AEAD 加密可防止数据篡改和流量特征泄露，降低被封锁和 DPI 检测风险。保证节点长期可用，提高数据传输安全性和访问可靠性，优化用户科学上网体验。
Vmess 节点可以通过 CDN 吗？
可以。Vmess 可通过 WebSocket 与 CDN 结合使用，只需将传输方式设置为 WS 并配置 host 与 path，即可实现流量中转。这样既能隐藏真实服务器，又能提升连接速度。
Potatso Lite 能否手动添加节点？
Potatso Lite 支持手动添加 Shadowsocks 节点。用户在“配置”中选择添加节点，输入服务器、端口、加密方式等信息即可建立连接，适合手动管理单个线路。
Surfboard 如何结合策略组实现智能分流？
Surfboard 可根据策略组和规则文件自动选择最优节点处理流量。不同应用或网站可分配不同节点，保证低延迟和高速访问，同时减少手动切换节点的操作。
Clash 的 Rule Provider 有什么作用？
Rule Provider 是 Clash 的规则分发机制。用户可以订阅不同的规则集，比如广告拦截、社交媒体、流媒体等，实现按需加载。它让配置文件更加简洁、动态更新，并支持多源规则管理。
